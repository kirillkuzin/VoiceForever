        Окно игры

        Агент печатает только в активное окно игры. Достаточно совпадения по названию окна или по имени процесса.

        Названия окнаwindow_titles
        Процессы игрыprocess_names
        Нажми, затем за 5 секунд переключись в игру: агент сам добавит её окно и процесс.
