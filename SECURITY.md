# Security

## Reporting a vulnerability

Do not open a public issue. Report it privately on GitHub: **Security** tab → **Report a vulnerability** ([direct link](https://github.com/kirillkuzin/VoiceForever/security/advisories/new)). Say what is affected, how to reproduce it and what an attacker gains.

Examples of what to report: a phrase or message that runs a game command, a way to reach another player's app or bot, a token or key leak, a recording or message that crashes the server.

## Supported versions

Fixes go into the [latest release](https://github.com/kirillkuzin/VoiceForever/releases/latest) and the `latest` server image. If you host the server yourself, update with `docker compose pull && docker compose up -d`.
